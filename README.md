## Overview

Phones carry an accelerometer and a gyroscope, but they never see the label "walking" or "still". The activity is hidden behind noisy signals. This project records my own motion data for four activities and recovers the hidden activity with a Hidden Markov Model (HMM) written from scratch in NumPy.

Activities: **Standing, Walking, Jumping, Still**

**Use case:** a low-cost activity monitor for elderly people and patients recovering at home in Rwanda, where dedicated wearables are expensive but smartphones are common. Knowing when someone has stayed still for too long, or suddenly becomes very active, lets a family member or community health worker check in early.

Each file in `Formative2_Clean/` is named `<activity>_<rate>hz_<number>.csv`, for example `jumping_50hz_01.csv`. The rate in the name is the rate the file was originally recorded at. Every file has been resampled to 50 Hz.

## Method

### 1. Pre-processing
* Both ZIP levels are extracted, and each file's sampling rate is measured from its nanosecond timestamps instead of trusting the folder name. This caught the two Standing folders, which were labelled the wrong way round.
* 100 Hz files pass a 4th order Butterworth low-pass filter at 20 Hz, then every file is resampled onto a uniform 50 Hz grid. 50 Hz is the lower common rate, and human motion sits below 20 Hz, so nothing useful is lost.
* 0.25 s is trimmed at both ends of each file to remove the tap on the start and stop button, and files are capped at 10 s.

### 2. Windowing and features
2 second windows (100 samples) with 50% overlap. A window covers at least three steps or jumps, and gives an FFT resolution of 0.5 Hz.

| Feature | Domain | Purpose |
|---|---|---|
| `acc_std`, `acc_rms`, `acc_sma` | Time | Movement intensity |
| `gyr_rms`, `gyr_std` | Time | Rotation, separates a held phone from one on a table |
| `corr_yz` | Time | Coupling of vertical and forward motion |
| `tilt_deg` | Time | Phone angle to gravity |
| `dom_freq` | FFT | Step or jump rhythm |
| `spec_energy` | FFT | Total spectral power |
| `spec_entropy` | FFT | Rhythmic motion versus flat noise |

Intensity features are log-transformed, then all features are Z-score normalized using training data only.

### 3. Hidden Markov Model
* **States:** the 4 activities
* **Observations:** a 10-dimensional feature vector per window
* **Emissions:** one Gaussian per state with diagonal covariance
* **Training:** parameters start from the labelled training windows, then Baum-Welch refines them until the log-likelihood gain per window drops below 1e-4
* **Decoding:** Viterbi
* Everything runs in log space to avoid underflow. No HMM library is used.

### 4. Train and test split
For each activity, one 50 Hz and one 100 Hz recording are held out, 8 recordings in total. They are never used for training or for fitting the normalization. They form two test files:
* `test_sequence_1.csv`: 50 Hz session, order Still, Standing, Walking, Jumping
* `test_sequence_2.csv`: 100 Hz session, reverse order Jumping, Walking, Standing, Still

The remaining 42 recordings are chained into 8 training sessions that follow a daily routine.

## Results on Unseen Data

| State (Activity) | Number of Samples | Sensitivity | Specificity | Overall Accuracy |
|---|---|---|---|---|
| Standing | 18 | 1.000 | 1.000 | 1.000 |
| Walking | 18 | 1.000 | 1.000 | 1.000 |
| Jumping | 15 | 1.000 | 1.000 | 1.000 |
| Still | 17 | 1.000 | 1.000 | 1.000 |
| **All windows** | **68** | **1.000** | **1.000** | **1.000** |

* Baum-Welch converged after 5 iterations.
* Both test files are decoded perfectly, including the reversed one, which uses transitions with a probability of 0.03 or less.
* Standing versus Still is the hardest pair. Only gyroscope sway and phone tilt separate them.
* In a noise test, accuracy falls to about 0.69 when noise with a standard deviation of 1 is added to the features. The emissions become overconfident, and the transition matrix adds little.

## Limitations
* All data comes from one person, one phone and one day. The perfect test score shows that these four activities separate clearly. It does not prove the same score for another person or phone position.
* The transition matrix reflects my scripted recording routine, not a natural day.
* Diagonal Gaussians treat correlated features as independent evidence, which makes emissions overconfident under noise.
